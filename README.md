# 厚涂笔触回放 V3

将照片转换为由粗到细绘制的厚涂风格笔触画。通过网页选择图片、笔刷、方向场和细化程度，生成各阶段图片，并回放完整的绘制过程。

## 功能

- 提供圆头刷、椭圆刷、扁平刷、长条刷和刮刀 5 种笔刷。
- 支持 Sobel 边缘方向场和 Structure Tensor 局部方向场。
- 通过最小颗粒度和迭代次数控制笔触块面与细节程度。
- 提供“经典铺色”和“流韵厚涂”两套绘画预设，支持独立调整画法参数并保存个人预设。
- 支持播放、暂停、进度拖动和阶段跳转；超过 10 个阶段的列表默认折叠。
- 保存最终预览图、阶段图片、阶段总览和笔触数据，按图片及绘制参数分别管理结果。

## 启动项目

### 运行环境

- Windows
- Python 3.11，安装后可使用 `py -3.11` 命令
- Microsoft Edge

### 安装依赖

在项目根目录打开 PowerShell，执行：

```powershell
py -3.11 -m pip install -r requirements.txt
```

### 启动与关闭

双击项目根目录的 `run.bat`，或在 PowerShell 中执行：

```powershell
.\run.bat
```

启动后会自动打开网页。默认地址为 http://127.0.0.1:8765/web/replay.html 。如果端口已占用，程序会在 8765～8774 中选择可用端口，以启动窗口显示及浏览器打开的地址为准。

使用期间保持启动窗口打开。关闭该窗口或按 `Ctrl+C` 可停止服务。更新项目后，先关闭启动窗口，再重新运行 `run.bat`。

需要指定端口时，可执行：

```powershell
py -3.11 server.py --port 8766 --open
```

## 使用方法

### 生成笔触画

1. 将图片放入 `input/` 文件夹。
2. 在网页上方的“生成操作台”点击“刷新列表”，选择输入图片。
3. 选择绘画预设，按需调整笔刷、方向场、颗粒度和迭代次数；“高级画法参数”中可调整笔触、压感、颜料和笔数。
4. 点击“生成笔触”，等待进度完成。生成完成后，回放区会自动载入新结果。

支持 PNG、JPG、JPEG、WebP、BMP、TIF 和 TIFF，文件名可包含中文和空格。图片宽高均需至少 32 像素；最长边超过 1024 像素时会等比例缩小，透明区域以白色填充。

### 调整绘制效果

先选择绘画预设，可以一次应用全部绘画参数和回放节奏：

| 预设 | 默认画法 |
| --- | --- |
| 经典铺色 | 保留单点印章、全局误差选点、目标图取色和阶段透明度的画法，默认每帧一笔回放 |
| 流韵厚涂 | 圆头刷、Structure Tensor、35→1 px、10 阶段；使用纹理笔尖、连续曲线、局部连续落笔、模拟压感、暗到亮的用色顺序和渐干覆盖，默认最多 12000 笔、每帧一笔回放 |

修改任意绘画参数后，预设会变为“自定义”。输入名称并点击“保存 / 更新预设”，即可保存到项目根目录的 `presets.json`，下次启动后仍可选择。修改已保存的个人预设后，可使用原名称更新，也可更换名称另存。内置预设保持只读。

`presets.json` 包含两个内置预设和已保存的个人预设，可通过页面链接下载。输入图片和当前回放文件分别选择，不包含在绘画预设中。

| 参数 | 作用 | 默认值 |
| --- | --- | --- |
| 笔刷 | 选择笔触形状。椭圆刷最多前 3 阶段使用纯圆起稿，最后一阶段使用椭圆 | 椭圆刷 |
| 方向场 | Sobel 跟随局部边缘；Structure Tensor 汇总邻域梯度，获得更稳定的方向 | Sobel |
| 最小颗粒度 | 从 1 px 到起始笔刷尺寸。数值越大，保留的笔触块面越明显；数值越小，细节越多 | 5 px |
| 迭代次数 | 至少 2 次，可拖动滑块或直接输入数字。每次迭代对应一个阶段，每阶段绘制多笔 | 10 次 |

起始笔刷尺寸默认为 35 px，可在高级参数中调整。网页从起始尺寸到所选最小颗粒度等距划分各阶段尺寸，并显示尺寸序列。例如，起始 35 px、最小 5 px、迭代 10 次时：

```text
35 → 31.67 → 28.33 → 25 → 21.67 → 18.33 → 15 → 11.67 → 8.33 → 5 px
```

笔刷尺寸以输出画布为准。迭代次数没有固定上限，次数越多，生成时间和输出文件数量也会增加。

“高级画法参数”提供以下独立选项：

| 维度 | 可调内容 |
| --- | --- |
| 笔刷表现 | 几何笔尖、纹理笔尖及纹理强度 |
| 笔触形态 | 单点印章、连续曲线及笔触长度 |
| 落笔组织 | 全局选点、局部连续绘制及停留程度 |
| 轻重动态 | 阶段透明度、模拟压感与起收笔及变化强度 |
| 用色顺序 | 目标图原色、暗部到亮部及顺序约束强度 |
| 颜料覆盖 | 均匀覆盖、拖笔渐干及颜料量 |
| 优化目标 | 还原优先、少笔优先 |
| 总笔数 | 0 为自动预算；正整数为总笔数上限 |
| 随机种子 | 控制生成中的随机采样 |

压感由程序模拟，笔触宽度仍受最小颗粒度限制；暗到亮控制选点顺序，不会统一压暗原图颜色。总笔数上限越小，可用于细化的笔触越少。

### 查看与回放

在“输出与回放”下拉框中选择已保存的结果。列表会显示图片名称、笔刷、方向场、阶段数和尺寸范围。

- 点击“一键播放”“暂停”或“重置”控制绘制过程。
- 拖动进度条，或点击阶段按钮，跳转到对应的绘制位置。
- 阶段列表默认显示前 10 个，展开后的列表在固定高度内滚动。
- 点击“最终预览图”或“阶段总览”查看导出的图片。
- 在“查看生成参数与版本”中查看预设、完整参数、随机种子和代码指纹，也可将结果参数载入生成操作台。
- 两种回放节奏均支持倍速，生成任务运行期间也可调整。“每帧一笔”以单笔作为逻辑帧；高倍速时，一次屏幕刷新可显示多笔的累计结果。

生成区和回放区独立操作，切换生成参数不会切换当前回放。已保存的结果可直接回放，无需再次生成。

## 输入与输出

服务启动时会自动创建缺失的 `input/` 和 `output/` 目录。仓库通过 `.gitkeep` 保留这两个目录，输入图片及生成结果保存在本地。全项目的 JPG/JPEG 文件均已加入 Git 忽略规则。

结果保存到以下目录：

```text
output/<图片文件名>/<笔刷>-<方向场>/<起始尺寸>-<最小尺寸>px-<迭代次数>stages/
```

例如，`source.png` 使用椭圆刷、Sobel、最小 5 px、迭代 10 次时：

```text
output/source.png/ellipse-sobel/35-5px-10stages/
├─ preview.png                 # 最终预览图
├─ stage_contact_sheet.png     # 阶段总览
├─ strokes.json                # 回放笔触数据
├─ generation.json             # 生成参数
├─ refinement_metrics.json     # 各阶段的生成统计
└─ stages/
   ├─ stage_01.png
   ├─ ...
   └─ stage_10.png
```

不同图片或不同参数组合分别保存。使用完全相同的图片文件名及绘制参数重新生成时，会替换对应结果；生成失败时保留已有文件。

使用高级画法或不同随机种子时，目录名会追加参数标识，区分同图、同笔刷和同阶段数的不同结果。`generation.json` 和 `strokes.json` 记录完整参数、预设名称、算法版本及代码指纹；每条曲线笔触还记录路径和压力变化，供回放与对照使用。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `run.bat` | Windows 启动入口 |
| `server.py` | 提供网页、图片列表、生成任务和结果查询 |
| `refine.py` | 生成笔触数据并导出图片 |
| `painting_settings.py` | 绘画参数校验和预设管理 |
| `presets.json` | 两个内置预设及个人预设 |
| `web/` | 生成操作台、回放页面和笔刷绘制代码 |
| `requirements.txt` | Python 依赖清单 |
