# 厚涂笔触回放 V3

从 `input/` 中选择图片，按画布与目标图的颜色及边缘误差生成由粗到细的笔触，保存各阶段图片并在网页中回放。默认从 35 px 缩小到 5 px，共 10 次迭代；可通过滑块控制最小颗粒度与迭代次数。

## 网页使用

本地运行环境为 Windows、Python 3.11 和 Microsoft Edge。首次使用先安装依赖：

```powershell
py -3.11 -m pip install -r requirements.txt
```

1. 将图片放入项目根目录的 `input/` 文件夹。
2. 双击 `run.bat`，浏览器自动打开回放网页。
3. 在顶部“生成操作台”选择输入图片、笔刷和方向场，拖动最小颗粒度与迭代次数滑块，确认尺寸序列后点击“生成笔触”。生成时显示当前阶段进度，完成后自动载入新结果。
4. 在下方“输出与回放”选择 `output/` 中已保存的结果，点击播放、暂停、拖动进度条，或按阶段跳转。

新增图片后点击“刷新列表”，外部新增输出后点击“刷新输出”。支持 PNG、JPG、JPEG、WebP、BMP、TIF 和 TIFF，文件名可包含中文和空格。每次只生成一张图片。生成区与回放区分别选择，修改生成选项不会切换当前回放；即使输入图片已删除，保存的输出仍可回放。

更新 Python 代码后，需要关闭原来的 CMD 窗口，再运行 `run.bat`，使用它新打开的网页。仅刷新网页不会更新正在运行的 Python 进程。网页会检查服务版本，旧版本或运行后代码发生变化时会禁止生成并提示重启，避免忽略新参数后仍按旧默认值生成。

## 颗粒度与迭代次数

- 最小颗粒度：网页可选 1～35 px，默认 5 px。值越大，越能保留明显的笔触块面。这个尺寸是输出画布上的笔刷尺寸，不是原图缩放前的尺寸。
- 迭代次数：至少 2 次，默认 10 次，不设固定上限。可用滑块或直接输入数字；输入超过滑块范围时，滑块会自动扩展。每次迭代对应一个阶段，不是单根笔触；每阶段仍会按画面误差绘制多笔。次数越多，生成时间、笔触数量和输出文件数量也会增加。
- 尺寸划分：从 35 px 到所选最小颗粒度等距划分，包含起点和终点。候选笔触也不会小于设置的最小值。

例如最小 5 px、迭代 10 次，对应名义尺寸：

```text
35 → 31.67 → 28.33 → 25 → 21.67 → 18.33 → 15 → 11.67 → 8.33 → 5 px
```

阶段之间不只是尺寸不同：目标图的模糊尺度随尺寸变化，笔触预算随尺寸及画布面积变化；透明度、落笔区域偏好和边缘误差权重随迭代进度变化。减少迭代次数会减少阶段和笔触总预算；提高最小颗粒度会限制最终细化程度。

## 笔刷与方向场

| 笔刷 | 标识 | 形状与阶段规则 |
| --- | --- | --- |
| 圆头刷 | `round` | 所有阶段均为纯圆 |
| 椭圆刷 | `ellipse` | 最多前 3 阶段强制纯圆；迭代不足 4 次时缩短圆刷阶段，保证最后使用椭圆 |
| 扁平刷 | `flat` | 各阶段均为扁平矩形 |
| 长条刷 | `long` | 各阶段均为细长、略带圆角的长条 |
| 刮刀 | `knife` | 各阶段均为带斜边的不对称刀痕 |

以上笔刷都从大号铺色逐渐缩小到细节刻画。去掉了固定白色刷毛线，所有笔触颜色都根据目标图和当前画布拟合。

方向场提供两种选择，均沿结构的切线方向排列笔触：

- `sobel`：使用 3×3 Sobel 算子检测局部边缘，取梯度方向加 90°，响应轮廓和明暗交界。
- `tensor`：对 Sobel 梯度的邻域统计构建 Structure Tensor，取局部主方向的切线，减少单像素噪声对角度的影响。邻域随笔刷尺度调整。

平坦区域或方向不可靠时采用 45°，圆形笔触的外形不受角度影响。当前没有头发、脸部、衣服等语义区域识别。

## 影响画面的维度

| 维度 | 当前控制方式 |
| --- | --- |
| 笔刷形状 | 网页或命令行选择；椭圆刷前期有纯圆约束 |
| 笔触尺寸与阶段 | 按滑块指定的最小尺寸与次数等距划分；比较原尺寸和较小尺寸候选，但不低于最小值 |
| 笔触方向 | 网页选择 Sobel 或 Structure Tensor |
| 颜色 | 对实际笔刷覆盖区域求颜色拟合，考虑当前画布和透明度 |
| 覆盖与透明度 | 前期较实，后期较轻；非圆笔刷比较不同透明度的候选 |
| 落笔区域 | 综合单点及邻域误差选点，对失败位置降权 |
| 结构保留 | 误差包含 RGB、亮度、边缘残差；后期提高边缘权重 |
| 目标尺度 | 前期参照模糊目标，后期逐渐接近清晰原图 |
| 笔触数量与停止 | 达到阶段笔触预算、尝试上限或候选误差足够小时结束 |

笔触候选只在降低综合误差时被接受。`refinement_metrics.json` 中的 `lossBefore/lossAfter` 记录综合误差，`mseBefore/mseAfter` 单独记录 RGB 误差；综合误差下降不要求 RGB 误差每次也下降。不同阶段的模糊尺度和权重不同，误差应在同一阶段内比较。

必须通过 `server.py` 启动服务；原来的 `python -m http.server` 只能提供静态文件，无法执行生成操作。默认使用 8765 端口；如果端口已占用，会在 8765～8774 中选择可用端口，并打开实际地址。也可以指定端口：

```powershell
py -3.11 server.py --port 8766 --open
```

## 输入与输出

服务启动时会自动创建缺失的 `input/` 和 `output/` 目录。Git 只跟踪两个目录的 `.gitkeep` 占位文件，原图及生成结果均保留在本地；项目中其他位置的 JPG/JPEG 文件也被忽略，扩展名大小写不限。首次获取项目后，请自行将图片放入 `input/`。

图片宽高均需至少 32 像素。生成前按 EXIF 方向校正，透明区域以白色填充；最长边超过 1024 像素时等比例缩小，阶段图片和回放均使用这个尺寸。

结果独立输出到 `output/<完整图片文件名>/<笔刷标识>-<方向场标识>/<起始尺寸>-<最小尺寸>px-<迭代次数>stages/`。同图的不同笔刷、方向、颗粒度和次数均分别保存，输出下拉框会标明尺寸范围和阶段数。

```text
input/
  source.png
  photo.jpg
output/
  source.png/
    ellipse-sobel/
      35-5px-10stages/
        strokes.json            # 完整笔触指令，包含每笔形状、尺寸、方向和颜色
        preview.png             # 最终笔触画布
        stage_contact_sheet.png # 阶段总览
        refinement_metrics.json # 每阶段笔触数及前后误差
        generation.json         # 输入摘要、画布尺寸、笔刷、方向及颗粒度参数
        stages/
          stage_01.png
          ...
          stage_10.png
      35-8px-4stages/
        ...
    ellipse-tensor/
      ...
    knife-sobel/
      ...
  photo.jpg/
    ...
```

重新生成只替换同图、同笔刷、同方向、同尺寸范围和同迭代次数的结果，保留其他组合。所有新文件导出成功后再替换原结果；生成失败时保留之前的结果。输入图片内容变化后，生成区将其标记为未生成；输出区仍保留以前保存的结果。

旧版输出仍会出现在输出列表中，并标记“旧版”。旧版预览图保存的是原来的渲染效果；当前回放已去掉白色刷毛线，要获得与当前回放一致的预览图需重新生成。

生成流程从空白画布开始，不依赖旧版的 10 阶段备份。预览图和阶段图片与网页共用笔刷实现，最终画面完全由笔触绘制。

## 命令行生成

在项目根目录执行：

```powershell
py -3.11 refine.py --image "photo.jpg"
py -3.11 refine.py --image "photo.jpg" --stages 16
py -3.11 refine.py --image "photo.jpg" --stages 10 --min-diameter 5
py -3.11 refine.py --image "photo.jpg" --brush knife --direction tensor
```

`--image` 指定 `input/` 中的文件名，默认 `source.png`。`--stages` 为不小于 2 的整数，默认 10，不设固定上限；`--min-diameter` 默认 5，`--max-diameter` 默认 35，可在命令行调整起始尺寸。尺寸必须满足 `1 ≤ 最小尺寸 ≤ 起始尺寸 ≤ 256`。`--seed` 指定随机种子，默认 20261110；`--browser` 可指定 Chromium 或 Edge 的完整程序路径。命令行和网页使用同一套生成逻辑，请避免同时对同一结果执行命令行和网页生成。

## 验证

```powershell
py -3.11 -B -m unittest discover -s tests -v
```

测试使用独立临时目录，检查笔刷形状、Sobel 梯度、Structure Tensor 方向、网页生成、图片及笔刷输出隔离、输入删除后的回放、失败保留旧结果，以及回放与新版导出图片的一致性。

## 说明

这是误差驱动的程序化笔触重建，不是闭源图像模型的内部绘制轨迹。它尽量从粗到细重建参考图，不保证与原照片逐像素一致。
